Encapsulation: going down the stack

Sending adds headers on the way down; receiving strips them on the way up (de-encapsulation). Layers 5–7 all call their PDU simply data.

Gray areas and how this game treats them

  • ARP sits between Layers 2 and 3 (it maps IP to MAC). Sources disagree, so it is not a scored card. If your class notes place it, follow your notes.
  • TLS/SSL encrypts data, which the OSI textbook mapping assigns to Layer 6. In real stacks it runs above TCP, so some references call it 5 or “between 4 and 7”. The game uses Layer 6.
  • NIC and wireless access point straddle Layers 1 and 2. The MAC address and framing make Layer 2 the usual answer; the radio or cable signal itself is Layer 1.
  • NAT vs PAT: NAT rewrites IP addresses (Layer 3). PAT also tracks port numbers (Layer 4).
  • Segmentation vs fragmentation: TCP segments data at Layer 4; IP fragments packets that exceed the link MTU at Layer 3.
  • Devices “at” a layer: routers also have Layer 1–2 interfaces, and firewalls can inspect from Layer 3 up to Layer 7. Questions mean the highest layer the device makes decisions on.
